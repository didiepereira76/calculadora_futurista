# Calculadora Futurista

Projeto de uma calculadora basica feita com HTML, CSS e JavaScript. A interface usa um visual escuro e futurista, com botoes estilizados e display responsivo.

## Funcionalidades

- Soma, subtracao, multiplicacao e divisao
- Botao de limpar (`C`)
- Troca de sinal (`+/-`)
- Calculo de porcentagem (`%`)
- Suporte a numeros decimais
- Tratamento de operacoes invalidas
- Layout responsivo para diferentes tamanhos de tela

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Estrutura do projeto

```text
calculadora_basica/
├── index.html
├── index.js
├── style.css
└── README.md
```

## Como executar

1. Abra a pasta `calculadora_basica`.
2. Clique duas vezes no arquivo `index.html`.
3. A calculadora sera aberta no navegador.

Tambem e possivel abrir o arquivo diretamente pelo navegador usando a opcao "Abrir arquivo".

## Como usar

- Clique nos numeros para montar a operacao.
- Use os operadores `+`, `-`, `x` e `÷`.
- Clique em `=` para ver o resultado.
- Clique em `C` para limpar o display.
- Use `%` para transformar o valor atual em porcentagem.
- Use `+/-` para inverter o sinal do valor atual.
